# dbtcloud_project (Resource)


Manages a dbt Cloud project.

## Example Usage

```terraform
resource "dbtcloud_project" "dbt_project" {
  name = "Analytics"
}
resource "dbtcloud_project" "dbt_project_with_description" {
  name = "Analytics with description"
  description = "My awesome analytics project"
}

resource "dbtcloud_project" "dbt_project_with_subdir" {
  name                     = "Analytics in Subdir"
  dbt_project_subdirectory = "path"
}

# a global connection the project uses for analytics
resource "dbtcloud_global_connection" "analytics" {
  name = "Analytics connection"
  snowflake = {
    account   = "my-snowflake-account"
    database  = "ANALYTICS"
    warehouse = "ANALYTICS_WH"
    allow_sso = false
  }
}

resource "dbtcloud_project" "dbt_project_with_analytics_connection" {
  name                    = "Analytics with an analytics connection"
  analytics_connection_id = dbtcloud_global_connection.analytics.id
}
```

## Schema

### Required

- `name` (String) Project name

### Optional

- `analytics_connection_id` (Number) ID of the global connection used for analytics. It must be a connection of the same account. Removing it from the configuration clears it, and so does leaving it out of the configuration when a value was set outside Terraform. Read-only users of the project query through the analytics credential of this connection, so the connection should have one. Deleting that credential clears the attribute.
- `dbt_project_subdirectory` (String) DBT project subdirectory
- `description` (String) Description for the project. Will show in dbt Explorer.
- `type` (Number) The type of dbt project (0=default or 1=hybrid)

### Read-Only

- `id` (Number) The ID of the project.

## Import
