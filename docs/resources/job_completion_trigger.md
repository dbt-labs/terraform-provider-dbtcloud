# dbtcloud_job_completion_trigger (Resource)


Manages a job completion trigger, which fires a downstream job when an upstream job reaches certain statuses. Use this resource instead of the `job_completion_trigger` block on `dbtcloud_job` to break circular dependency chains.



<!-- schema generated by tfplugindocs -->
## Schema

### Required

- `job_id` (Number) The ID of the downstream job that will be triggered.
- `project_id` (Number) The dbt Cloud project ID.
- `statuses` (Set of String) The set of job completion statuses that trigger the downstream job. Valid values: `success`, `error`, `canceled`.
- `trigger_job_id` (Number) The ID of the upstream job whose completion fires this trigger.

### Read-Only

- `id` (Number) The ID of the downstream job (same as `job_id`).
