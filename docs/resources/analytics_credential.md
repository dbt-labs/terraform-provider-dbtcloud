# dbtcloud_analytics_credential (Resource)


Analytics credential of a global connection: the warehouse credentials dbt platform uses to read the data of an analytics connection.

~> The analytics credentials endpoints are not public yet. They need the `cc-4192-enable-analytics-credentials` flag enabled on the account.

The adapter is fixed by the connection: set exactly one adapter block, and it must match the adapter of the connection. Changing the adapter block, or the `auth_type` of an adapter block, recreates the credential. Optional attributes of an adapter block cannot be removed once set; recreate the credential to clear them.

Secrets are write-only (`*_wo`, with a `*_wo_version` to trigger a rotation) and are never stored in the state. This needs Terraform >= 1.11.

Snowflake password authentication is deprecated on the server.
