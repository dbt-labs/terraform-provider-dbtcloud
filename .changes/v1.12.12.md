# [v1.12.12](https://github.com/dbt-labs/terraform-provider-dbtcloud/compare/v1.12.11...v1.12.12)
### Fixes
* Fix import/refresh of `bigquery_v1` `dbtcloud_global_connection` resources: `use_latest_adapter` is now derived from the API's adapter version instead of being left unset, avoiding a false "Adapter version cannot be changed" error, and `timeout_seconds` (a `bigquery_v0`-only field) is no longer sent on update for `bigquery_v1` connections (#709).
* project resource's Delete (soft-delete via UpdateProject) no longer validates dbt_project_subdirectory, so legacy projects whose subdirectory predates today's validation rules (e.g. a leading "/") can be destroyed instead of erroring forever
* project updates no longer send `connection_id`, so applying `dbtcloud_semantic_layer_configuration` or `dbtcloud_project_artefacts` no longer cascades the project connection onto every environment and overrides their global connection IDs (#516)
### Behind the scenes
* move repository ownership to the cloud-config team
