# [v1.12.2](https://github.com/dbt-labs/terraform-provider-dbtcloud/compare/v1.12.1...v1.12.2)
### Fixes
* Fix `Provider produced inconsistent result after apply` on `dbtcloud_job` when `job_type` is set to `scheduled` but the dbt platform API derives `other` (or vice versa). These two labels are interchangeable values the API derives from whether a schedule trigger is active and cannot be enforced, so the provider now preserves the configured/prior label for the `scheduled`<->`other` pair (on create, update, and read) while keeping `ci`/`merge`/`adaptive` authoritative. The `job_type` attribute description is also corrected to reflect that `scheduled`/`other` are inferred rather than enforceable.
